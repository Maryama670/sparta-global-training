# Structuring Typology Guide

Structuring is the deliberate splitting of larger transactions into smaller transactions in order to avoid detection, review, or reporting requirements.

## Warning signs

1. Multiple similar-value transactions over a short period.
2. Multiple accounts sending funds to the same counterparty.
3. Activity that does not match the customer's expected profile.
4. Repeated transfers that appear deliberately fragmented.
5. Shared counterparties, corridors, or transaction patterns across several accounts.

## Analyst procedure

1. The analyst must review all linked transactions.
2. The analyst must identify the accounts involved.
3. The analyst must compare the activity with the customer's expected monthly activity and source of funds.
4. The analyst must review linked counterparties and previous alerts.
5. If the activity cannot be reasonably explained, the analyst should recommend escalation.
6. If important information is missing, the analyst should request further information.

## Example

Three customers send £3,200, £3,100 and £2,900 to the same counterparty. One customer is a student whose expected monthly activity is £1,500. The transactions should be reviewed together because the shared counterparty and similar amounts may indicate coordinated structuring.
