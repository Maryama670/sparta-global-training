# AML Case Handling Procedure

This procedure sets out how analysts must manage AML cases from opening through review and closure.

## Case opening

1. A case must be created when one or more alerts require investigation together.
2. The analyst must record the linked alert IDs.
3. The analyst must identify the accounts, transactions and counterparties involved.
4. The case record must contain a clear reason for opening the investigation.
5. The analyst must record the date the case was opened and the current case status.

## Investigation

1. The analyst must review all linked alerts and transactions.
2. Related alerts should be grouped where they share an account, counterparty, corridor or other meaningful characteristic.
3. The analyst must compare customer activity against occupation, expected monthly activity and source of funds.
4. Any missing information must be documented.
5. The analyst must record evidence supporting both suspicious and non-suspicious explanations.
6. The analyst must avoid closing a case until all material alerts have been reviewed.

## Outcome

A case may result in:
- escalation;
- request for more information;
- recommendation for closure;
- referral for suspicious activity reporting.

The final decision must be made by an authorised human reviewer.

## Example

Alerts 21 and 24 involve the same account and the same overseas counterparty. Instead of reviewing them separately, the analyst opens one case containing both alerts. The analyst reviews all linked transactions and documents the shared counterparty relationship before making a recommendation.
